# NSR-1 printable tray — rev B2

`nsr1_tray.step` and `nsr1_tray.stl` are generated by `build_tray.py`
(FreeCAD 1.0 Part API). The tray is the case shell only: 406 × 176 × 35 mm
outside, 2.4 mm walls, 2 mm floor, an open 400 × 170 mm panel recess, and
printed M3 board posts for the keyboard and under-mounted control board.

This is the first printable shell, not the final panel. The faceplate,
screen/key/encoder cutouts, rear connector openings, and lid/lip details are
still to be modelled. Regenerate with:

```bash
freecadcmd hardware/enclosure/build_tray.py
```
