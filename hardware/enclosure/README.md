# NSR-1 printable tray — rev B2

`nsr1_tray.step/.stl` and `nsr1_faceplate.step/.stl` are generated by the
FreeCAD scripts in this directory. The tray is 406 × 176 × 35 mm outside,
2.4 mm walls, 2 mm floor, an open 400 × 170 mm panel recess, and printed M3
board posts for the keyboard and under-mounted control board. The faceplate
contains the rev B2 key, screen, encoder, pot, transport, slider, joystick,
and mic cutouts.

Rear I/O openings and the final lid/lip details are still to be modelled.
The Blender exploded/assembled renders are generated by
`hardware/enclosure/render_exploded.py` and `label_render.py`; see
[`docs/renders/`](../../docs/renders/).

Regenerate the CAD with:

```bash
freecadcmd hardware/enclosure/build_tray.py
freecadcmd hardware/enclosure/build_faceplate.py
```
