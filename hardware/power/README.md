# NSR-1 power/battery board

Source of truth: [`netlist-spec.md`](netlist-spec.md). This board is common to
the NSR-1 platform and future SBC carriers.

## Status

- `power.kicad_pcb` — outline and mounting holes generated by
  `hardware/tools/make_platform_outlines.py`; 90 × 60 mm with 4× M3 holes.
- Schematic — not generated yet. The candidate charger/boost/gauge parts and
  the power-path decisions are frozen in the spec before schematic work.
- Layout — not started; power-board and battery bays are specified in
  [`../enclosure-spec.md`](../enclosure-spec.md).

## Checks

```bash
cd hardware/power
kicad-cli pcb drc power.kicad_pcb --output /tmp/power-drc.json --format json --severity-all
```
